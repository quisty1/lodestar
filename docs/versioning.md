# Versioning policy — Lodestar

## Single source of truth

Версия живёт **только** в `package.json` → `version`. `manifest.config.ts` читает
`pkg.version`. Git-тег на релиз — опционально.

## SemVer

| Что изменилось                                     | Бамп      |
| -------------------------------------------------- | --------- |
| Ломающее изменение публичного контракта расширения | MAJOR     |
| Новая фича/модуль                                  | MINOR     |
| Багфикс / UX-проход / рефактор / debt              | PATCH     |
| Чистая документация / контекст                     | без бампа |

## Ритуал релиза

1. Определить тип (MAJOR/MINOR/PATCH) по таблице.
2. Поднять `package.json` → `version` и синхронизировать `package-lock.json`.
3. Обновить описание актуального поведения в `README.md`.
4. Выполнить `npm run release:check`.
5. Бамп идёт в финальном коммите фичи или отдельным `chore(release): vX.Y.Z`.

Политика применяется при подготовке релиза; чистка документации не требует бампа.
